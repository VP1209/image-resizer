# Same-Size Image Resizer

Resize horizontal and vertical images to one exact width and height, entirely in the browser.

- Crop to fill, fit with bars, blurred-edge extend, or stretch
- Series file names (prefix + start number)
- JPG / PNG / WebP output, single or ZIP download
- No backend: images never leave your device

## Use
Open `index.html` in a browser, or host it with GitHub Pages.

## Stack
HTML, CSS, vanilla JavaScript, Canvas API, JSZip (CDN).
